# 0006. Dynamic Model Discovery, Full-Packet Read-Only Review, and Strict Completion Gates

Status: accepted

Real-world `/ale` runs on `line-bot-waifu` and `antigravity-skills` exposed five failure modes in the v2 harness: (1) static model maps in `ledger.py` fell behind host model releases (missing all five `gemini-4-neon-*` and `gemini-pro-orchestrator-neon` models, silently normalizing them to `gemini-4-argon-high`); (2) `invoke_agy_model` treated exit-0 JSON error envelopes (`is_error: true` or `status: ERROR`, such as quota exhaustion) as valid outputs and turned them into `REFUTED` verdicts instead of advancing through the cross-family fallback chain; (3) passing the full diff inline via `-p` argv hit the 65 KB cap and Linux's 128 KB `MAX_ARG_STRLEN` limit on large or pre-existing dirty trees, leaving core modules and tests unreviewed; (4) `VERIFIED_WITH_CAVEATS` passed the review gate even when findings carried `must-fix` severity, and `strike-breaker` fallback could re-edit an already modified workspace after a timeout; and (5) `ruling --complete` closed sessions while active `SESSION_LL` invariants remained unresolved.

We decided to:
1. Replace hardcoded model lists with a **Dynamic Model Registry** in `ledger.py` that queries `agy models` (with short-lived local caching and a static fallback catalog when `agy` is unavailable), ranks models by family, generation version, capability tier (`neon > carbon > argon > hydrogen > flash`; `opus > sonnet`), and effort (`high` default for flagships, `xhigh` for explicit overrides or Tier 3 `fast-exec`), and supports optional user overrides (`exclude`, `pin_role`, `prefer_effort`) in `$HOME/tmp/ale_harness/model_routing.json` (respecting `ALE_OUTPUT_ROOT`).
2. Inspect parsed JSON error envelopes inside `invoke_agy_model` so quota or transport errors advance through the cross-family fallback chain instead of consuming Friction Budget, and disable automatic fallback for `strike-breaker` whenever `git status --porcelain` changed after the first attempt.
3. Write the full uncapped diff, untracked files, baseline dirty-tree snapshot (`baseline.patch` / `baseline_dirty_files` recorded at `init`), test output, and deduplicated `LESSONS_LEARNED` rules into `<session_dir>/review_packet.md`. Keep `-p` compact so small diffs finish in one turn while instructing read-only reviewers (`ALE_SUBPROCESS_ROLE=review`, write tools blocked by `pretool_gate.py`) to inspect `<session_dir>/review_packet.md` or workspace files via `read_file` whenever truncated.
4. Reject `VERIFIED_WITH_CAVEATS` when any finding has `severity == "must-fix"` (allowing `should-fix` and `nice-to-have` caveats to pass while surfacing open `should-fix` counts), and require every active `SLL-*` entry in `SESSION_LL.md` to be either promoted (`promote-ll`) or explicitly dismissed (`dismiss-ll`) before `ruling --complete` succeeds.
